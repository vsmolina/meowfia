# Meowfia

Website for a cardboard-cat-vehicle TikTok creator: templates, kits, merch, memberships, community gallery, and admin.

The app lives in [`meow-app/`](meow-app/). See **[meow-app/README.md](meow-app/README.md)** for setup (it runs on **port 3847**), environment variables, deployment, and the go-live checklist.

```bash
cd meow-app && npm install && cp .env.example .env && npm run setup && npm run dev
# → http://localhost:3847
```
